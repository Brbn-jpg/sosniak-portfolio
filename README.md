# SosniakPortfolio

SosniakPortfolio is a personal portfolio website built for Sebastian Sośniak.
It uses Astro, TypeScript and Tailwind CSS, and is deployed at
[metricmind.pl](https://metricmind.pl).

Read the [SosniakPortfolio case study](https://www.brbn.pl/projects/sosniak-portfolio)
for the architecture, trade-offs and verified project scope.
